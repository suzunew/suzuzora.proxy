# suzuzora proxy

Koyebで動かせる、軽量な日本語優先Webプロキシです。ゲーム、チャット、SNSなどの専用機能は含めず、URL入力・DuckDuckGo検索・Webページ閲覧に絞っています。

## 特徴

- Node.js 24 / Express 5
- DuckDuckGoを標準検索エンジンに設定（日本向け `kl=jp-jp`）
- 閲覧ページ内のJavaScript言語設定を `ja-JP` 優先にする
- gzip圧縮、静的ファイルキャッシュ、軽量な独自UI
- 戻る・進む・再読み込み・ホームへ戻る
- `/health` ヘルスチェック
- Koyeb Dockerfile対応
- パスワード認証なし。アクセス時のログイン画面もありません

## Koyebへのデプロイ

1. このフォルダーの内容をGitHubリポジトリへアップロードします。
2. Koyebで **Create App → GitHub** を選択し、リポジトリとブランチを指定します。
3. Builderは **Dockerfile** を選びます。
4. 公開ポートを `8080 / HTTP` にします。
5. Health check pathを `/health` に設定してDeployします。

環境変数は通常 `NODE_ENV=production` のみで動作します。ポートはKoyebの `PORT` 環境変数を自動的に利用します。

## ローカル起動

```bash
npm install
npm start
```

`http://localhost:8080` を開きます。Service Workerを利用するため、公開環境ではHTTPSが必要です。

## 日本語表示について

検索はDuckDuckGoの日本向け設定で実行します。閲覧ページ内では `navigator.language` / `navigator.languages` を日本語優先にします。サイトが日本語表示を提供していれば日本語版が選ばれやすくなりますが、サイト側の仕様・アカウント設定・言語選択によっては英語などで表示されます。これはページ本文を機械翻訳する機能ではありません。

## 重要：認証なしの公開プロキシ

この構成はパスワード認証を意図的に設けていません。そのため、デプロイ先URLを知っている人は誰でも利用できます。第三者による大量アクセスでKoyebの通信量や利用料金が増える可能性があります。必要に応じてKoyeb側の利用上限、インスタンス制限、アクセス制御を設定し、公開先と利用状況を管理してください。

## 動作上の制約

高速化のための圧縮・キャッシュ・軽量UIを採用していますが、実際の速度はKoyebのリージョン・インスタンス性能・接続先サイト・ネットワーク状況に左右されます。すべてのサイト、ログイン、動画、WebSocket、決済ページなどの動作を保証するものではありません。アクセス先の利用規約と法令を守ってください。

## OSSライセンス

このプロジェクトは複数のオープンソースライブラリを利用しています。著作権表示・ライセンス条件を確認できるよう、`NOTICE` の記載を残してください。ライブラリ本体の名称を画面上のブランドやナビゲーションには表示していませんが、依存パッケージ名や法的な帰属表示まで削除するものではありません。
